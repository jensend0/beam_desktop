# Beam Designer

Beam Designer is a Python desktop app for analyzing simply supported beams and cantilevers. Set the span, supports, loads, material, and section to view shear, moment, and deflection diagrams, design checks, and a section recommendation. Save or open beam files and export results as CSV or a calculation sheet as PDF.

## Requirements

- Python 3
- Tkinter (included with most Python installations; no third-party packages are required)

## Start the app

From the project directory, run:

```sh
python3 beam_designer.py
```
